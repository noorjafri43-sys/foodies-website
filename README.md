# 🍽️ Foodies - Restaurant Landing Page

A fully responsive restaurant landing page built with pure **HTML, CSS, and JavaScript** — no frameworks, no dependencies.

## 🔗 Live Demo
[View Live Site](https://foodies-website-nu.vercel.app)

## ✨ Features

- ✅ Fully responsive (mobile + desktop)
- ✅ Sticky navigation bar
- ✅ Animated scroll reveal on sections
- ✅ Interactive FAQ accordion
- ✅ Auto-rotating testimonials carousel
- ✅ Newsletter subscription with validation
- ✅ No external JS libraries — vanilla JS only
- ✅ Google Fonts (Playfair Display + Inter)
- ✅ Unsplash CDN images (no local assets needed)

## 🚀 Getting Started

### Option 1 — Open Locally
Just download `index.html` and open it in any browser. Done.

### Option 2 — GitHub Pages (Free Hosting)
1. Create a new GitHub repo (e.g. `foodies-website`)
2. Upload `index.html` → rename it to `index.html`
3. Go to **Settings → Pages → Branch: main → Save**
4. Your site goes live at:
   ```
   https://yourusername.github.io/foodies-website
   ```
